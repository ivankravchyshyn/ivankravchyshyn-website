3. Self-hosted fonts

The Barlow Condensed font files used on this website are stored with the website and delivered from the same hosting location. Opening the website therefore does not create a connection to an external font provider.

4. Analytics, advertising, cookies and browser storage

This website does not use analytics services or advertising trackers and does not set non-essential cookies. The public website does not use localStorage or sessionStorage for tracking. A development-only typography diagnostic, which is available only when explicitly requested with the ?diagnostic=1 parameter, can store local calibration values in localStorage; those values are not used for tracking and are not used during an ordinary visit.

5. Contact by e-mail

This website has no contact form. If a visitor independently sends an e-mail, the sender address, message content and any other data supplied with the message are processed only to handle and answer the enquiry. Depending on the subject of the enquiry, the legal basis is Article 6(1)(b) GDPR for pre-contractual or contractual communication, or Article 6(1)(f) GDPR for other correspondence. The legitimate interest is the appropriate handling of the enquiry. The data is deleted when it is no longer required for that purpose, unless statutory retention obligations apply.

6. External links

The website contains external links to YouTube, IMDb, LinkedIn and Crew United. It does not embed players or content from these providers. No data is transferred by this website to those providers merely by viewing a page. Only after a visitor actively clicks an external link does the browser establish a connection to the selected provider; that provider then receives technically necessary request data and processes it under its own privacy terms.
